# DESIGN SYSTEM

## Purpose

This document defines the visual language of the Mayank Portfolio.

Every component, page, animation, and interaction should follow these rules.

---

# Visual Direction

Style:

Premium
Minimal
Futuristic
Engineering-focused

Reference feeling:

Modern technology companies
Premium SaaS products
High-end developer tools

---

# Layout System

Principles:

- Large whitespace
- Strong visual hierarchy
- Minimal clutter
- Content appears with purpose
- Avoid unnecessary elements

---

# Background

Primary:

Near Black

#050505

Use:
- subtle gradients
- soft glow effects
- minimal noise texture

Avoid:
- distracting backgrounds
- excessive particles

---

# Colors

Background:

---

# Typography

Style:

Large bold headlines.

Clean readable body text.

Priority:

1. Message
2. Visual hierarchy
3. Decoration

---

# Components

All components should have:

- Consistent spacing
- Rounded corners
- Smooth hover states
- Clean borders
- Premium feel

---

# Animation Principles

Animations should:

- Feel natural
- Guide attention
- Never distract

Preferred:

- Fade
- Slide
- Scale
- Blur transition
- Smooth hover interaction

Avoid:

- Excessive bouncing
- Random effects
- Over-animation

---

# Responsive Design

The website must support:

Desktop first

Tablet

Mobile

Every section should adapt gracefully.

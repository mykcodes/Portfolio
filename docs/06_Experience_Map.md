# EXPERIENCE MAP

## Purpose

Define the complete journey a visitor experiences when exploring the Mayank Portfolio.

The website should feel like entering a carefully designed digital experience, not simply browsing a resume.

---

# Visitor Journey

## 1. Opening Experience

Goal:

Create immediate curiosity.

Experience:

- Smooth loading transition
- Brand identity appears
- Subtle animation
- Website feels premium from the first second

---

# 2. Hero Section

Purpose:

Immediately communicate identity.

Contains:

- Name
- Personal tagline
- Short introduction
- Primary action
- Secondary action

The visitor should understand:

Who is Mayank?

What does he build?

Why should they continue?

---

# 3. Identity Section

Purpose:

Humanize the developer.

Contains:

- Background
- Engineering philosophy
- Current focus
- Goals

The focus is storytelling, not a boring biography.

---

# 4. Project Showcase

Purpose:

Show proof of ability.

Projects should feel like products.

Each project contains:

- Project name
- Problem solved
- Technology used
- Development story
- Result
- Links

---

# 5. Technology Section

Purpose:

Show technical foundation.

Display:

- Languages
- Frameworks
- Tools
- Current learning

Avoid simple skill lists.

Make it interactive.

---

# 6. Journey Timeline

Purpose:

Show growth.

Contains:

- Learning milestones
- Projects
- Achievements
- Future goals

---

# 7. Content Creation Section

Purpose:

Connect technical work with personal brand.

Show:

- Coding content
- Tutorials
- Build journey
- Social links

---

# 8. Contact Section

Purpose:

Make connection easy.

Contains:

- Email
- GitHub
- LinkedIn
- Social platforms

---

# Overall Feeling

After visiting the website, the user should think:

"This person is serious about engineering."

"This person builds things."

"This person has attention to detail."

---

# Navigation Philosophy

Navigation should be:

- Minimal
- Smooth
- Always accessible
- Experience-focused

Avoid traditional corporate navigation.

## Design Goal

A recruiter should feel:

"This is one of the best portfolios I've seen."

The website should communicate quality through simplicity rather than visual overload.

## Design Language

Overall Feel

- Premium
- Confident
- Minimal
- Clean
- Engineering-first

Rules

- No visual clutter
- Large typography
- Plenty of whitespace
- Smooth animations
- Rounded corners
- Soft shadows
- Glassmorphism only where it adds value
- Every animation should have a purpose
- Focus on storytelling instead of showing everything at once

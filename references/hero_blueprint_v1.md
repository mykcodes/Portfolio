# HERO BLUEPRINT V1

## Goal

The hero section should not feel like a landing page.

It should feel like entering a premium software product.

The visitor should immediately think:

- This person has exceptional engineering taste.
- This person builds products.
- This is different.

---

## Screen

Desktop First

100vw
100vh

The hero occupies the entire first screen.

No scrolling required to understand the message.

---

## Background

Near black (#050505)

Very subtle radial gradient.

Interactive network of tiny glowing nodes.

Behavior:

- Nodes slowly drift.
- Nearby nodes softly connect.
- Mouse movement gently pushes nearby nodes.
- Small glow follows the cursor.
- No bright colors.
- No gaming effects.

The interaction should feel alive but calm.

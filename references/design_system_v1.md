# PROJECT MAYANK — DESIGN SYSTEM V1

Version: 1.0

---

# Philosophy

The website must feel like a premium software product.

Not a portfolio.

Not a resume.

Not a template.

The design language should communicate:

- Confidence
- Precision
- Engineering
- Simplicity
- Calmness

Visitors should feel:

"This person has exceptional product taste."

# Hero

Full viewport.

Large empty space.

Centered.

---

# Scroll

No hard cuts.

No sudden movement.

---

# Images

Avoid stock photos.

# Icons

Minimal.

# Performance

60 FPS minimum.

Animations must remain smooth.

Never sacrifice performance for effects.

---

# Quality Standard

Every new section should answer:

Would this look believable on the website of a world-class software company?

If not,

redesign it.
